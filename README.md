# L’atelier du magazine

Un modèle de magazine people à personnaliser (couverture, sommaire, scoop, grand reportage,
interview, album photo, « Ils ont dit », horoscope, recette, quiz, petites annonces, courrier
des lecteurs, mot de la fin), à remplir directement dans le navigateur puis à imprimer en A4.

Tout tient dans un seul fichier, `index.html` : pas d’installation, pas de serveur.

## Utilisation

1. Ouvrez `index.html` dans Chrome, Edge, Firefox ou Safari.
2. Cliquez sur un texte gris pour l’écrire, sur un cadre pour ajouter une photo
   (une fois placée, faites-la glisser pour la recadrer ; survolez-la pour zoomer ou la changer).
3. Ajoutez, dupliquez, déplacez ou supprimez des pages avec les boutons au-dessus de chacune.
4. « Aperçu » masque les aides pour voir le rendu final.
5. « Imprimer / PDF » : choisissez « Enregistrer au format PDF », papier A4, marges « Aucune »,
   et cochez « Graphiques d’arrière-plan ».

## Remplir à plusieurs

Le travail est enregistré automatiquement dans le navigateur utilisé (photos comprises).
Pour faire circuler le magazine dans la famille :

- « Exporter » télécharge un fichier `.json` contenant tout le magazine ;
- la personne suivante ouvre `index.html`, clique sur « Importer », remplit sa rubrique,
  puis exporte à son tour.

## Mise en ligne

Le fichier peut être publié tel quel, par exemple avec GitHub Pages
(Settings → Pages → branche principale, dossier racine).
